# 山札大貧民

パスのときに山札から1枚引ける大貧民です。ブラウザで遊べます。CPUと3〜5人で対戦します。

昔、UNOのカードで遊んだ「パスしたら山から引ける大貧民」をトランプで再現しました。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。インストールもビルドも不要です。

## ルール

- 全員に8枚ずつ配り、残りは山札にします（配る枚数は設定で変更可）。手札を先に出し切った人の勝ちです。
- 場の札より強い札を、同じ枚数・同じ形で出します。強さは 3＜4＜…＜K＜A＜2（＜ジョーカー）。
- 出せる形は、1枚・同じ数字の2〜4枚・同じスートで3枚以上の連番（階段）です。
- **パスするとき、山札から1枚引いてもかまいません**（引かなくてもいい）。引いた札はその番には出せません。
- 最後に札を出した人まで順番が戻ったら場が流れ、その人が好きな札から始めます。

### 特殊な札

| 札 | 効果 |
| --- | --- |
| 7 | リバース：順番の向きが逆になる |
| 8 | 8切り：場が流れ、出した人がもう一度出す |
| 9 | スキップ：次の人を飛ばす（2枚なら2人） |
| J | 11バック：場が流れるまで強さが逆転 |
| 同じ数字4枚／同スート5連番 | 革命：局の終わりまで強さが逆転 |
| ♠3 | 1枚出しのジョーカーに勝ち、場が流れる |

### 縛り

同じ場で2回続けて条件がそろうと、場が流れるまで縛りがかかります。複数の縛りが重なることもあります。

- **色縛り**：赤黒の組み合わせが同じ出し方が2回続くと、以後その色の組み合わせしか出せない
- **スート縛り**：マークの組み合わせが同じ出し方が2回続くと、以後そのマークしか出せない
- **数字縛り**：ちょうど1つ強い数字が2回続くと、以後も1つ強い数字しか出せない（3→4なら次は5、345→456なら567）

### 禁止上がり

次の札を含む出し方では上がれません。ペアや階段に含まれる場合も同じです。

- 2（革命中は3）・8・J・ジョーカー
- ジョーカーを切る♠3

手札がこれらの札だけになったら、場が空でもパスできます。パスのときに山札から1枚引いて抜け出しましょう。全員が出せず山札も引けなくなったら、手札の少ない順に順位を決めます。

### 局と身分

上がった順に大富豪・富豪・平民・貧民・大貧民になります。2局目からは配ったあとにカードを交換し、大貧民から始めます。

各ルールはゲーム内の「設定」からオン・オフできます。
